 🕵️ Data Detective

Data Detective is a Python based game created as part of the Introduction to Data Science course.

The idea behind this project is to make learning data science more interesting through games and real life situations. Instead of simply reading concepts or answering MCQs, players learn by investigating different cases, analysing data and making decisions.

 About the Game

The game starts with choosing a detective character. Players then have to solve five different cases, each based on a data science concept.

Every case presents a situation where players need to study the given data, identify patterns and find the correct explanation.

Solving a case earns experience points and unlocks the next level.

 Game Levels

Level 1: The Missing Clue**

Learn how to identify and handle missing values in a dataset.

Level 2: The Suspicious Delivery

Find unusual values in a dataset and understand outlier detection.

Level 3: The Study Secret

Explore the relationship between study hours and examination scores using correlation.

Level 4: The Biased Survey

Understand sampling bias and why selecting a representative sample is important.

Level 5: The Ice Cream Mystery

Discover the difference between correlation and causation through an interesting real life situation.

 Features

1. Choose from four different detective characters.
2. Explore five levels with different challenges.
3. Analyse datasets and interactive graphs.
4. Make decisions based on the available evidence.
5. Get hints when stuck.
6. Earn XP points for solving cases.
7. Unlock new levels as you progress.
